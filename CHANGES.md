# What changed after the Meridian work

Lessons from running this end to end, folded into v2 of the kit.

1. **Two phases, not one.** The first kit only covered the canvas. The deck is where the decision gets made; the canvas is where it gets proven. Both are now specced.
2. **Positioning map needs a recalibration rule.** First pass had incumbents evenly spread, which says nothing. Rule added: change axes until they cluster and a quadrant is empty.
3. **Direction slides in their own system.** Setting all six directions in the deck's house type made them look alike. Each direction slide now uses its own palette and faces.
4. **Spec before HTML, on named axes.** Directions drifted toward "warm minimal" ×3 until we forced ≥3 named axes of difference and random draws.
5. **Wordmark rules, motion, iconography, form states, grid.** Missing from boards 2a–2c; now sections 10–13, added when a direction wins rather than on every board.
6. **Contrast ratios on every pairing.** Two of the first palettes failed AA on body text and were only caught when the ratios were written on the board.
7. **Risk line per direction.** Summaries read like sales copy without it.
8. **Market spelling as an input.** We shipped British spelling into a US brand once. MARKET is now a required input.
9. **Hosting + skill export as the last step.** The canvas becomes a single self-contained HTML for a subdomain, and the winner becomes an application skill with tokens. Both are now in the process.
10. **Banned lead faces.** Fraunces, Inter, Roboto, Arial lead too many first drafts; listed.
